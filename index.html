Amazon S3 Bucket Setup & Settings

Connect your personal Amazon S3 bucket to store and retrieve your documents securely from AWS Amplify.

API Gateway connects to your Lambda function to securely upload to your private S3 bucket without exposing credentials.
Paste the Invoke URL from your AWS API Gateway dashboard.
1 Create Private S3 Bucket
In AWS S3, create bucket named myvaultbypriyanshu-documents. Leave "Block all public access" ENABLED (checked).
2 Create Lambda Function
In AWS Lambda → Create function → Name: myvault-backend, Runtime: Python 3.12.
Paste the code from lambda_function.py in this project repository.
Under Configuration → Permissions, ensure the execution role has permission for S3: 
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "s3:ListBucket",
        "s3:GetObject",
        "s3:PutObject",
        "s3:DeleteObject"
      ],
      "Resource": [
        "arn:aws:s3:::myvaultbypriyanshu-documents",
        "arn:aws:s3:::myvaultbypriyanshu-documents/*"
      ]
    }
  ]
}
3 Create API Gateway
In AWS API Gateway → Create HTTP API → Add integration with your Lambda myvault-backend.
Under CORS, enable CORS with * or your Amplify domain.
Copy the generated Invoke URL (e.g. https://xyz123.execute-api.us-east-1.amazonaws.com).
4 Connect in CloudVault
In the ⚙️ S3 Configuration tab, select AWS API Gateway + Lambda, paste your Invoke URL, click Test, and click Save Configuration.
